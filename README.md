# Fraud-Detection-in-Credit-Card-Transactions-
Goal: Identify fraudulent transactions with minimal False Positive Rate.  Worked with a highly imbalanced dataset (1000:17 fraud ratio). Random Forest achieved 0.78 Recall, improved to 0.82 with Isolation Forest. Deep Autoencoder model achieved 0.85 Recall with 6.5% FPR. Used Python, PCA, ML models for anomaly detection. 🚀
